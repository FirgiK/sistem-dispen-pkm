# Form Design Check
1. One question per field, neutral wording.
2. Required only when the purpose fails without it.
3. Single choice for mutually exclusive answers, free text only when a list would miss real cases.
4. Easy questions first; group related fields.
5. Test with an incomplete answer and, for this project, with no network connection.
