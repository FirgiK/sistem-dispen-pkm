# Verify Terminal Commands
1. Run one diagnostic first (example: ls -la) and read its output before acting on it.
2. Never assume a filename, version, or folder name.
3. Give one exact copy-paste step at a time and state the expected output.
4. A failed command is new evidence: change one thing, never repeat the same command blindly.
5. Label any unverified part of a command as a guess.
